DEPOT COCKPIT PWA v3.7

Für GitHub Pages müssen diese 5 Dateien im Hauptordner des Repositories liegen:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

Wichtig:
Die persönlichen Depotdaten und der API-Key bleiben im lokalen Speicher des Browsers.
Sie sind NICHT in diesen Dateien enthalten.

Nach dem Upload:
1. GitHub Pages öffnen.
2. Seite einmal neu laden.
3. In Chrome sollte „App installieren“ erscheinen.
4. Alternativ: Chrome-Menü ⋮ → App installieren / Zum Startbildschirm hinzufügen.

Live-Kurse brauchen Internet.
Die App-Oberfläche kann nach der ersten erfolgreichen Installation auch offline starten.
